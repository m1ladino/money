    Prvo podešavanje — radi se jednom

    Napravi svoj besplatan privatni prostor za podatke. Traje oko 5 minuta i ne plaća se ništa.

    1. Otvori supabase.com i napravi nalog (može preko Google naloga).
    2. Klikni New project, daj mu ime zarada, izmisli lozinku baze i sačuvaj je negde. Sačekaj minut-dva da se napravi.
    3. Sa leve strane otvori SQL Editor, nalepi tekst ispod (dugme „Kopiraj") i klikni Run.
    4. Sa leve strane otvori Project Settings → API i prekopiraj dve stvari u polja ispod: Project URL i ključ anon public.
    Tekst za SQL Editor (klikni da vidiš)
    create table if not exists public.prodaje ( id bigint primary key, user_id uuid not null default auth.uid() references auth.users on delete cascade, proizvod text not null, kolicina numeric not null, nabavna numeric not null, prodajna numeric not null, datum date not null, created_at timestamptz default now() ); alter table public.prodaje enable row level security; create policy "samo svoje" on public.prodaje for all to authenticated using (auth.uid() = user_id) with check (auth.uid() = user_id);

    Prijavi se

    Ovim mejlom i lozinkom ulaziš u svoju aplikaciju sa bilo kog uređaja. Prvi put klikni „Napravi nalog".
